# assistencia-tecnica-aspnet
Sistema de Assistência Técnica  Projeto desenvolvido em ASP.NET Web Forms com C# e SQL Server.  
Funcionalidades:
- Cadastro de Clientes
- Cadastro de Técnicos
- Cadastro de Equipamentos
- Cadastro de Ordens de Serviço
- Alteração de registros
- Exclusão de registros
- Consulta através de GridView

## Tecnologias

- ASP.NET Web Forms
- C#
- SQL Server
- Bootstrap
